# 全家附近好物（非官方）

手機友善的繁體中文網頁，把全家便利商店公開的[友善食光地圖](https://foodmap.family.com.tw/)與[挖寶專區地圖](https://dz5iap6aj0of3.cloudfront.net/)回傳的商品，依店代碼整合在同一間分店下。可收藏常去分店、搜尋已載入店家的店名／地址／店代碼，或以瀏覽器定位找附近約一公里內的店。未允許定位時也可選擇地區中心或手動輸入座標；知道店代碼的人可以直接收藏，即使官方地圖暫時沒有回傳商品資料也不會刪除收藏。

**本網站不是全家官方網站，也不是全臺分店名錄或即時／完整庫存。** 只顯示兩張地圖在查詢時回傳的店與商品。商品數量和資料時間完全以該地圖回應為準；空回應、未列出店家、查詢失敗各有不同提示，皆不能據以認定分店缺貨。實際商品以現場與官方地圖為準。

## 本機執行

需 Node.js 20.19+（20 LTS）、22.12+（22 LTS）或 24 LTS。在此儲存庫目錄執行：

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run check` 可單獨檢查 TypeScript。建置產物位於 `dist/`，Vite 的 `base` 已設為 `/familymart_map/`，可直接部署在本儲存庫的 GitHub Pages 專案網址。

## 資料與隱私

- 僅呼叫 `https://stamp.family.com.tw/api/maps/MapProductInfo`，分別使用官方公開地圖代碼 `202106302`（友善食光）與 `202208202`（挖寶專區）；`MapList` 曾用來核對名稱、連結與代碼，不在頁面載入時額外請求。API 不使用會員權杖或登入憑證。
- 店代碼是合併鍵。收藏只在本機 `localStorage` 保存店代碼、店名和地址，不保存定位座標。瀏覽器定位僅在按「使用目前位置」後請求；查詢座標四捨五入至小數點後四位，只送至全家地圖 API。地區預設座標僅代表標示地點附近，非整個行政區的搜尋。
- 未設定查詢位置時，會以固定參考座標查詢**收藏店代碼**，只顯示收藏店結果，不會誤把參考座標附近店家當作使用者附近店家。附近位置圖為頁面自行繪製的相對示意，不載入任何第三方圖磚。
- 同一位置與同一組店代碼的查詢在本頁記憶體中快取五分鐘；手動強制重新查詢至少須間隔一分鐘。資料服務／格式錯誤會顯示錯誤，不會以假資料替代。請避免自動化或頻繁要求官方服務。

## 部署

推送至 `main` 會啟動 `.github/workflows/deploy.yml`：安裝鎖定依賴、執行測試與型別檢查／建置，再使用 GitHub Pages Actions 發佈 `dist/`。**首次部署前**，具有儲存庫管理權限的人須在 Settings → Pages 將 Build and deployment 來源設為 **GitHub Actions**；僅有程式碼寫入權限的人無法自行啟用 Pages。若先推送程式碼，設定完成後可手動重新執行此部署 workflow。成功後網址為 <https://zero0415.github.io/familymart_map/>。Pages、Actions 與第三方公開 API 若停用或調整，請先檢查工作流程、官方地圖連結及瀏覽器錯誤提示。
