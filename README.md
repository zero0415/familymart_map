# 全家附近好物（非官方）

手機友善的繁體中文網頁，把全家便利商店公開的[友善食光地圖](https://foodmap.family.com.tw/)與[挖寶專區地圖](https://dz5iap6aj0of3.cloudfront.net/)回傳的商品，依店代碼整合在同一間分店下。可收藏常去分店，輸入店名／地址／店代碼查找已載入的店並直接收藏；若未定位，可輸入三位數郵遞區號查詢該區的地圖資料再按名稱篩選。也可用瀏覽器定位、地區中心或手動座標找附近約一公里內的店。知道店代碼的人可以直接收藏，即使官方地圖暫時沒有回傳商品資料也不會刪除收藏。網站內建八種商品的收據參考價；商品有代碼時也能自行記錄折扣前個人原價，兩者不是官方定價。收藏店預設收合商品明細，展開後可再次收合；滑動較遠時有浮動的返回頁首連結。

**本網站不是全家官方網站，也不是全臺分店名錄或即時／完整庫存。** 只顯示兩張地圖在查詢時回傳的店與商品；沒有位置或郵遞區號時，無法僅憑店名搜尋全臺分店。此時可改用[全家官方店舖查詢](https://www.family.com.tw/Marketing/zh/Map)找店代碼，再回本站直接收藏。商品數量和資料時間完全以該地圖回應為準；空回應、未列出店家、查詢失敗各有不同提示，皆不能據以認定分店缺貨。實際商品以現場與官方地圖為準。

## 收藏、挖寶分類與圖片

- 「我的收藏」可用商品分類（全部／食品／用品／酒品／類別未知）與是否以「惜-」開頭交集篩選**挖寶專區商品明細**，並可清除篩選；**不需要選擇折數**。收藏分店本身、友善食光商品與附近店家清單均不受商品篩選影響；原有的店名／地址／店代碼搜尋仍照常搜尋店家。符合筆數只計入已回傳商品明細的收藏店；未回傳分店、查詢中、查詢錯誤與「無符合篩選商品」分開提示。
- 挖寶商品使用官方回應的**群組名稱**（不是商品細分類或名稱）判為「美味挖寶」食品、「生活好物」用品、「珍藏酒窖」酒品。名稱須以「惜—」或「惜-」開頭才屬惜字商品；常見破折號、全形橫線及空白變體也支援，名稱中間出現「惜」不算。

  | 挖寶群組／分類 | 惜字開頭 | 非惜字開頭 |
  | --- | --- | --- |
  | 美味挖寶／食品 | 估算5折 | 折扣未知 |
  | 生活好物／用品 | 估算3折 | 估算5折 |
  | 珍藏酒窖／酒品 | 折扣未知 | 折扣未知 |

  未知群組標示「類別／折扣未知」，不從商品名稱猜類別；酒品也不推測折數。**折數 badge 僅依使用者提供規則自動估算，不是官方 API 提供的折扣或實際結帳價格；實際優惠以官方／現場為準。** 不用個人紀錄的原價推算精確折後價（門市規則、結帳時機和四捨五入都可能影響實付）。友善食光商品不套用這套折數；附近店家的挖寶明細也會顯示標註，但附近清單不受收藏篩選影響。
- 收藏瀏覽卡與附近已收藏店只標示「已收藏」，不提供一鍵移除。請使用收藏區的「管理收藏」連結進入獨立管理清單；按「移除…」後須在顯示店名與店代碼的確認區再次按「確認移除」，也可按「取消」。附近尚未收藏的店仍可一鍵加入。
- 兩張地圖的商品若有官方商品代碼，可按「查看圖片」才向 `https://stamp.family.com.tw/api/maps/MapProductImage` 查詢，並僅載入官方 HTTPS 商品圖片網域的網址；不會在清單載入時大量請求圖片。圖片視窗可關閉或按 Escape，關閉後焦點回到原按鈕。沒有商品代碼、官方未提供圖片、服務錯誤或圖片無法載入時會明確提示，不會使用假圖片；並非所有商品都有圖。

## 公開的收據參考價（非官方）

- 網站直接內建[八種商品與官方商品代碼](src/receipt-prices.ts)的參考價，來源僅為使用者提供的 **2026-10-02 收據**。原價是該張收據當時標示的單件價格；「該筆五折推算」是逐件半價後遇到 .5 元進位至整元的結果，**不是官方定價、現在售價或未來優惠的保證**，也不依收據總額回推商品價格。
- 所有訪客可在網站「收據參考」區看到八種參考價，不必登入、定位或等地圖回傳商品；收藏與附近分店展開挖寶商品明細後，只有**官方商品代碼完全相同**才顯示這筆收據原價與五折推算。不同代碼、無代碼或友善食光的商品不套用這筆五折推算；不依名稱／惜字前綴猜售價，也不影響現有的分類、折數 badge、圖片與篩選。
- 內建參考價所有裝置皆可看見；**個人原價備註與收藏仍各自只存於該瀏覽器、不跨裝置同步**，個人輸入不會被參考價覆蓋。商品可能已停售或改價，實際優惠與庫存以現場及官方資訊為準。

## 個人原價紀錄（非官方）

- 在收藏店或附近店展開商品，對有**官方商品代碼**的商品按「記錄個人原價」，自行填入折扣前原價；已記錄的品項可修改、經確認後清除。相同代碼的商品在不同分店與兩張地圖共用同一筆個人紀錄，名稱相同但代碼不同（或無代碼）絕不混用。未記錄時只顯示「尚未記錄」，無代碼時提示無法記錄；不自動填任何價格。
- 頁首「原價紀錄」連到獨立管理區，列出所有記錄的商品名稱、代碼與**「個人紀錄原價／非官方」**價格；即使商品目前不在地圖，也能修改、清除既有紀錄。接受 NT$0.01～99,999.99 的正數金額，最多兩位小數；不接受逗號、貨幣符號、指數或負數。
- 官方公開 `MapProductInfo` 只提供商品 `code`、`name`、`qty`，`MapProductImage` 只提供 `imageUrl`；兩者都**沒有可用商品代碼核對的官方原價**。[全家鮮食商品頁](https://www.family.com.tw/Marketing/zh/FreshFood/Product)雖有部分原價，卻沒有可對照的同一商品代碼，不能依名稱、圖片或模糊配對當作官方定價。本網站不使用個人紀錄推算結帳價格；只有上述特定收據參考價會顯示當次逐件五折推算，不把個人紀錄或參考價宣稱為官方／實際結帳價格。

## 本機執行

需 Node.js 20.19+（20 LTS）、22.12+（22 LTS）或 24 LTS。在此儲存庫目錄執行：

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run check` 可單獨檢查 TypeScript。建置產物位於 `dist/`，Vite 的 `base` 已設為 `/familymart_map/`，可直接部署在本儲存庫的 GitHub Pages 專案網址。

## 資料與隱私

- 地圖資料僅呼叫 `https://stamp.family.com.tw/api/maps/MapProductInfo`，分別使用官方公開地圖代碼 `202106302`（友善食光）與 `202208202`（挖寶專區）。郵遞區號搜尋以 `PostInfo` 傳入三位數郵碼、以 `0, 0` 作為 API 需求的座標，不送出使用者定位；店名只在該查詢回傳的清單內篩選，不是跨全臺的店名查詢。有代碼的商品按「查看圖片」後，才另向同站官方 `MapProductImage` 查詢商品圖片網址，再從官方圖片網域載入圖片。`MapList` 曾用來核對名稱、連結與代碼，不在頁面載入時額外請求。API 不使用會員權杖或登入憑證。
- 店代碼是分店合併鍵；商品代碼是個人原價紀錄及內建收據參考價的精確對應鍵。八種內建參考價只含同意公開的商品代碼、品名、單價與一般收據日期，不含收據圖片、號碼、交易時間或分店資料；不是儲存在個人 `localStorage`。收藏與個人原價分別保存在本機 `localStorage`，原價紀錄只保存商品代碼、顯示名稱和自己輸入的原價，**不送往任何 API、不需登入、換裝置不會同步**；清除瀏覽器網站資料後也不會保留。收藏只保存店代碼、店名和地址，不保存定位座標。原價資料無法讀取、格式損壞或無法寫入時會明確提示，本次編輯僅留在目前頁面，不覆寫損壞資料，也不清除收藏。瀏覽器定位僅在按「使用目前位置」後請求；查詢座標四捨五入至小數點後四位，只送至全家地圖 API。地區預設座標僅代表標示地點附近，非整個行政區的搜尋。
- 未設定查詢位置且未選郵遞區號時，會以固定參考座標查詢**收藏店代碼**，只顯示收藏店結果，不會誤把參考座標附近店家當作使用者附近店家。選擇郵遞區號時會單獨查詢該區且不附上收藏店代碼，避免跨區收藏混入搜尋結果；已有的收藏另外查詢，仍可查看商品。附近位置圖為頁面自行繪製的相對示意，不載入任何第三方圖磚。
- 同一位置或郵遞區號與同一組店代碼的查詢在本頁記憶體中快取五分鐘；手動強制重新查詢至少須間隔一分鐘。資料服務／格式錯誤會顯示錯誤，不會以假資料替代。請避免自動化或頻繁要求官方服務。

## 部署

推送至 `main` 會啟動 `.github/workflows/deploy.yml`：安裝鎖定依賴、執行測試與型別檢查／建置，再使用 GitHub Pages Actions 發佈 `dist/`。**首次部署前**，具有儲存庫管理權限的人須在 Settings → Pages 將 Build and deployment 來源設為 **GitHub Actions**；僅有程式碼寫入權限的人無法自行啟用 Pages。若先推送程式碼，設定完成後可手動重新執行此部署 workflow。成功後網址為 <https://zero0415.github.io/familymart_map/>。Pages、Actions 與第三方公開 API 若停用或調整，請先檢查工作流程、官方地圖連結及瀏覽器錯誤提示。
