# 全家附近好物（非官方）

手機友善的繁體中文網頁，把全家便利商店公開的[友善食光地圖](https://foodmap.family.com.tw/)與[挖寶專區地圖](https://dz5iap6aj0of3.cloudfront.net/)回傳的商品，依店代碼整合在同一間分店下。可收藏常去分店，輸入店名／地址／店代碼查找已載入的店並直接收藏；若未定位，可輸入三位數郵遞區號查詢該區的地圖資料再按名稱篩選。也可用瀏覽器定位、地區中心或手動座標找附近約一公里內的店。知道店代碼的人可以直接收藏，即使官方地圖暫時沒有回傳商品資料也不會刪除收藏。收藏店預設收合商品明細，展開後可再次收合；滑動較遠時有浮動的返回頁首連結。

**本網站不是全家官方網站，也不是全臺分店名錄或即時／完整庫存。** 只顯示兩張地圖在查詢時回傳的店與商品；沒有位置或郵遞區號時，無法僅憑店名搜尋全臺分店。此時可改用[全家官方店舖查詢](https://www.family.com.tw/Marketing/zh/Map)找店代碼，再回本站直接收藏。商品數量和資料時間完全以該地圖回應為準；空回應、未列出店家、查詢失敗各有不同提示，皆不能據以認定分店缺貨。實際商品以現場與官方地圖為準。

## 收藏、挖寶篩選與圖片

- 「我的收藏」可用商品分類（全部／食品／用品／酒品／類別未知）、是否以「惜-」開頭，以及折數（全部／5折／3折／未知）交集篩選**挖寶專區商品明細**，並可清除篩選。收藏分店本身、友善食光商品與附近店家清單均不受商品篩選影響；原有的店名／地址／店代碼搜尋仍照常搜尋店家。符合筆數只計入已回傳商品明細的收藏店；未回傳分店、查詢中、查詢錯誤與「無符合篩選商品」分開提示。
- 挖寶商品使用官方回應的**群組名稱**（不是商品細分類或名稱）判為「美味挖寶」食品、「生活好物」用品、「珍藏酒窖」酒品。名稱須以「惜—」或「惜-」開頭才屬惜字商品；常見破折號、全形橫線及空白變體也支援，名稱中間出現「惜」不算。

  | 挖寶群組／分類 | 惜字開頭 | 非惜字開頭 |
  | --- | --- | --- |
  | 美味挖寶／食品 | 5折 | 折扣未知 |
  | 生活好物／用品 | 3折 | 5折 |
  | 珍藏酒窖／酒品 | 折扣未知 | 折扣未知 |

  未知群組標示「類別／折扣未知」，不從商品名稱猜類別；酒品也不推測折數。**折數僅依使用者提供規則判讀，不是官方 API 提供的折扣或結帳價格；實際優惠以官方／現場為準。** 友善食光商品不套用這套折數；附近店家仍依原方式顯示。
- 收藏瀏覽卡與附近已收藏店只標示「已收藏」，不提供一鍵移除。請使用收藏區的「管理收藏」連結進入獨立管理清單；按「移除…」後須在顯示店名與店代碼的確認區再次按「確認移除」，也可按「取消」。附近尚未收藏的店仍可一鍵加入。
- 兩張地圖的商品若有官方商品代碼，可按「查看圖片」才向 `https://stamp.family.com.tw/api/maps/MapProductImage` 查詢，並僅載入官方 HTTPS 商品圖片網域的網址；不會在清單載入時大量請求圖片。圖片視窗可關閉或按 Escape，關閉後焦點回到原按鈕。沒有商品代碼、官方未提供圖片、服務錯誤或圖片無法載入時會明確提示，不會使用假圖片；並非所有商品都有圖。

## 本機執行

需 Node.js 20.19+（20 LTS）、22.12+（22 LTS）或 24 LTS。在此儲存庫目錄執行：

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run check` 可單獨檢查 TypeScript。建置產物位於 `dist/`，Vite 的 `base` 已設為 `/familymart_map/`，可直接部署在本儲存庫的 GitHub Pages 專案網址。

## 資料與隱私

- 地圖資料僅呼叫 `https://stamp.family.com.tw/api/maps/MapProductInfo`，分別使用官方公開地圖代碼 `202106302`（友善食光）與 `202208202`（挖寶專區）。郵遞區號搜尋以 `PostInfo` 傳入三位數郵碼、以 `0, 0` 作為 API 需求的座標，不送出使用者定位；店名只在該查詢回傳的清單內篩選，不是跨全臺的店名查詢。有代碼的商品按「查看圖片」後，才另向同站官方 `MapProductImage` 查詢商品圖片網址，再從官方圖片網域載入圖片。`MapList` 曾用來核對名稱、連結與代碼，不在頁面載入時額外請求。API 不使用會員權杖或登入憑證。
- 店代碼是合併鍵。收藏只在本機 `localStorage` 保存店代碼、店名和地址，不保存定位座標。瀏覽器定位僅在按「使用目前位置」後請求；查詢座標四捨五入至小數點後四位，只送至全家地圖 API。地區預設座標僅代表標示地點附近，非整個行政區的搜尋。
- 未設定查詢位置且未選郵遞區號時，會以固定參考座標查詢**收藏店代碼**，只顯示收藏店結果，不會誤把參考座標附近店家當作使用者附近店家。選擇郵遞區號時會單獨查詢該區且不附上收藏店代碼，避免跨區收藏混入搜尋結果；已有的收藏另外查詢，仍可查看商品。附近位置圖為頁面自行繪製的相對示意，不載入任何第三方圖磚。
- 同一位置或郵遞區號與同一組店代碼的查詢在本頁記憶體中快取五分鐘；手動強制重新查詢至少須間隔一分鐘。資料服務／格式錯誤會顯示錯誤，不會以假資料替代。請避免自動化或頻繁要求官方服務。

## 部署

推送至 `main` 會啟動 `.github/workflows/deploy.yml`：安裝鎖定依賴、執行測試與型別檢查／建置，再使用 GitHub Pages Actions 發佈 `dist/`。**首次部署前**，具有儲存庫管理權限的人須在 Settings → Pages 將 Build and deployment 來源設為 **GitHub Actions**；僅有程式碼寫入權限的人無法自行啟用 Pages。若先推送程式碼，設定完成後可手動重新執行此部署 workflow。成功後網址為 <https://zero0415.github.io/familymart_map/>。Pages、Actions 與第三方公開 API 若停用或調整，請先檢查工作流程、官方地圖連結及瀏覽器錯誤提示。
