# 全家附近好物（非官方）

手機友善的繁體中文網頁，首頁保留[友善食光地圖](https://foodmap.family.com.tw/)與[挖寶專區地圖](https://dz5iap6aj0of3.cloudfront.net/)的官方連結、查詢狀態與資料提醒，並提供「開始找附近」「開始找收藏店家」兩個入口。導覽依序是**附近店家、收藏店家、收據參考、原價紀錄、資料說明**；品牌可回首頁。每次只顯示目前分頁，網址 `#nearby`、`#favorites`、`#receipt-prices`、`#price-notes`、`#about` 可直接開啟，瀏覽器返回／前進與切頁焦點可用；切頁不會重新查詢地圖或清除已輸入的表單和展開狀態。

**本網站不是全家官方網站。**「附近店家」按「使用目前位置」後，會依距離列出 3 公里內的店名、公里數及「+收藏／已收藏」；也可用地區中心、臺北市捷運站或手動座標，不須授權定位。清單來自公開店舖目錄**快照**，與商品地圖資料不同；店舖資料仍可能延遲、缺漏，不能當作商品庫存。地圖原先未回傳的店，商品只在展開清單或加入收藏後按需查詢；官方地圖未回傳、服務失敗及店碼／地點不符皆不代表缺貨。實際商品以現場與官方資料為準。

## 附近清單與店名搜尋

- GitHub Pages 發布時以一次公開 POST 擷取全家店舖目錄（目前約 4,432 筆），驗證格式、店碼唯一性與座標後，隨站點部署精簡的 `store-directory.json`。瀏覽器首頁**不下載整份目錄**；只在附近分頁選定位置，或收藏分頁實際提交店名搜尋時才載入，並在頁面內快取。清單顯示**快照擷取時間**和無法定位的店數；超過 48 小時會明示可能過期。官方原始資料現有一筆明顯錯誤座標：仍可依店名搜尋和收藏，但不能列入距離計算或安全核對商品。
- 商品地圖以座標且不帶店碼的查詢通常只回傳約 **1 公里**，單把半徑常數改為 3,000 公尺不會得到 3 公里完整清單。附近清單以目錄座標計算 3 公里範圍，並合併地圖實際回傳但不在目錄的車站店，避免原可見店消失或同店重複。清單**不是 3 公里完整商品庫存**：展開或收藏店家時，才以商品地圖舊店碼按需查詢；會核對回傳的店碼、店名和相近座標，不一致就停止顯示該店商品並告知原因。
- 店舖目錄的 `pkeynew` **不是**商品地圖的 `oldPKey`。例如全家台鐵一店的目錄碼 `023510`、`serid=58687`，商品地圖舊店碼為 `018687`。建置時只接受五位、指定範圍的 `serid`，依官方資料已核實的 1xxxx 減 10,000、5xxxx／6xxxx 減 40,000，左補零為六位舊店碼；搜尋結果收藏與商品查詢都使用**舊店碼**，不會把 `pkeynew` 存入收藏。
- 收藏分頁的「店名搜尋」使用全臺目錄快照尋找**新的**店，支援店名、地址或舊店碼；匹配結果可直接「+收藏」，不再過濾已收藏分店或附近清單。結果過多只先顯示前 30 間，可縮小條件。管理收藏上方仍可直接輸入**商品地圖舊店碼**，即使兩張地圖未回傳商品也保留收藏。移除收藏僅能在「管理收藏」經店名／店碼二次確認。
- 沒有定位權限時，地區中心與手動座標一樣可取得目錄的 3 公里清單。三位數郵遞區號保留為**商品地圖的區域備用查詢**，結果不是 3 公里名錄，也不會把其他區的收藏混入；可依[全家官方店舖查詢](https://www.family.com.tw/Marketing/zh/Map)核對。快照失敗時會顯示錯誤及重試，不會把約 1 公里的地圖結果誤稱完整 3 公里清單。
- 地區中心選單保留原有城市預設點，另依文湖、淡水信義、松山新店、中和新蘆及板南線分組提供**地址位於臺北市的捷運站**；轉乘站只在第一個站碼的路線出現一次。站名與座標取自臺北大眾捷運股份有限公司提供的[「臺北捷運車站資料」](https://data.gov.tw/dataset/131734)（[臺北市資料大平臺 CSV](https://data.taipei/api/dataset/1eefa68d-7c8d-491b-8e75-66a161947426/resource/c77e91bf-067c-475e-917b-545ff62b7d76/download)，2026-09-02 版；政府資料開放授權條款第 1 版）。以站點為中心查詢附近 **3 公里**，不是整個行政區。
- 成功提交目前位置、地區／捷運站、手動座標或三位數郵碼後，畫面會移到搜尋結果標題並將鍵盤焦點移至該處；重複查同一條件也會跳轉，無效表單與定位失敗則留在表單警告。郵碼結果**同樣跳到結果區**，但只有商品地圖回傳的分店，仍**依店名排序**，並非按距離排序或 3 公里完整清單；切換分頁或背景重新整理不會再強制跳回結果。

## 收藏、挖寶分類與圖片

- 收藏分店卡本身維持預設收合；展開收藏卡或附近店列後，「友善食光」與「挖寶專區」各有獨立、預設收合的商品區塊，摘要直接顯示查詢狀態與筆數（讀取失敗原因、未回傳不代表缺貨也可辨識）。需要看商品與資料時間時可各自展開，收合其中一區不會關閉另一區或分店；**桌機和手機一律上下排列**。附近店仍在展開店列後才按需查詢商品，不預查 3 公里內所有店。
- 只在展開「友善食光」區塊後顯示獨立的[官方活動規則](https://nevent.family.com.tw/cherishfood/)：當日 17:00 到期的鮮食自 10:00 起至到期前（10:00–17:00）、當日 24:00 到期的鮮食自 17:00 起至到期前（17:00–24:00），**符合商品效期與活動條件時享 7 折**；飯糰、壽司、手卷及便當、麵食、三明治等僅為品項舉例，不以品名推斷單件優惠。部分 FamiSuper 生鮮蔬果的「到期前 55 小時 7 折」僅見於[官網連結的過往報導](https://ent.ltn.com.tw/news/paper/1456103)，現行活動頁未明載，是否仍適用以最新官方公告與門市為準。商品地圖**沒有逐件原價、效期或當下優惠狀態**；店舖資料時間與 `periodType` 也不能作單件判斷。故不替友善商品逐件標折數、推算實付金額，未回傳、無明細、載入中或查詢失敗也不代表有貨或享優惠；使用者個人原價仍只供記錄。
- 「我的收藏」可用商品分類（全部／食品／用品／酒品／類別未知）與是否以「惜-」開頭交集篩選**挖寶專區商品明細**，並可清除篩選；**不需要選擇折數**。收藏分店本身、友善食光商品與附近店家清單均不受商品篩選或新增店名搜尋影響。符合筆數只計入已回傳商品明細的收藏店；未回傳分店、查詢中、查詢錯誤與「無符合篩選商品」分開提示。
- 挖寶商品使用官方回應的**群組名稱**（不是商品細分類或名稱）判為「美味挖寶」食品、「生活好物」用品、「珍藏酒窖」酒品。名稱須以「惜—」或「惜-」開頭才屬惜字商品；常見破折號、全形橫線及空白變體也支援，名稱中間出現「惜」不算。

  | 挖寶群組／分類 | 惜字開頭 | 非惜字開頭 |
  | --- | --- | --- |
  | 美味挖寶／食品 | 估算5折 | 折扣未知 |
  | 生活好物／用品 | 估算3折 | 估算5折 |
  | 珍藏酒窖／酒品 | 折扣未知 | 折扣未知 |

  未知群組標示「類別／折扣未知」，不從商品名稱猜類別；酒品也不推測折數。**折數 badge 僅依使用者提供規則自動估算，不是官方 API 提供的折扣或實際結帳價格；實際優惠以官方／現場為準。** 不用個人紀錄的原價推算精確折後價（門市規則、結帳時機和四捨五入都可能影響實付）。友善食光商品不套用這套折數；附近店家的挖寶明細也會顯示標註，但附近清單不受收藏篩選影響。
- 收藏瀏覽卡與附近已收藏店只標示「已收藏」，不提供一鍵移除。請使用收藏區的「管理收藏」連結進入獨立管理清單；按「移除…」後須在顯示店名與店代碼的確認區再次按「確認移除」，也可按「取消」。附近尚未收藏的店仍可一鍵加入。
- 兩張地圖的商品若有官方商品代碼，可按「查看圖片」才向 `https://stamp.family.com.tw/api/maps/MapProductImage` 查詢，並僅載入官方 HTTPS 商品圖片網域的網址；不會在清單載入時大量請求圖片。圖片視窗可關閉或按 Escape，關閉後焦點回到仍可見的原按鈕；若已切頁則回目前分頁標題。沒有商品代碼、官方未提供圖片、服務錯誤或圖片無法載入時會明確提示，不會使用假圖片；並非所有商品都有圖。

## 公開的收據參考價（非官方）

- 網站直接內建[八種商品與官方商品代碼](src/receipt-prices.ts)的參考價，來源僅為使用者提供的 **2026-10-02 收據**。原價是該張收據當時標示的單件價格；「該筆五折推算」是逐件半價後遇到 .5 元進位至整元的結果，**不是官方定價、現在售價或未來優惠的保證**，也不依收據總額回推商品價格。
- 所有訪客可在網站「收據參考」區看到八種參考價，不必登入、定位或等地圖回傳商品；清單預設收合，標題、筆數與來源說明仍可見，按「展開收據參考價清單」查看後可再次收合。收藏與附近分店展開挖寶商品明細後，只有**官方商品代碼完全相同**才顯示這筆收據原價與五折推算。不同代碼、無代碼或友善食光的商品不套用這筆五折推算；不依名稱／惜字前綴猜售價，也不影響現有的分類、折數 badge、圖片與篩選。
- 內建參考價所有裝置皆可看見；**個人原價備註與收藏仍各自只存於該瀏覽器、不跨裝置同步**，個人輸入不會被參考價覆蓋。商品可能已停售或改價，實際優惠與庫存以現場及官方資訊為準。

## 個人原價紀錄（非官方）

- 在收藏店或附近店展開商品，有**官方商品代碼**的商品會在同一個價錢區塊顯示收據原價／逐件五折推算及收據日期（若有精確對碼）。未記錄時左側顯示說明、右側為小型「記錄個人原價」按鈕；已有紀錄則左側顯示目前價格、右側為「修改個人原價」，文字可換行，320px 螢幕也不應橫向溢出。按下才開啟標示「使用者自行記錄價格（折扣前原價，非官方，NT$）」的較窄金額欄位與儲存／取消；已有紀錄會預填，可經再次確認後清除。收據價仍有獨立區塊，沒有收據價的商品不再被整列價格編輯框佔滿；按鈕維持鍵盤可用與至少 44px 高的觸控區。相同代碼的商品在不同分店與兩張地圖共用同一筆個人紀錄，名稱相同但代碼不同（或無代碼）絕不混用。無代碼時提示無法記錄，不自動填任何價格；個人紀錄不改動收據參考價，也不拿來推算五折。
- 頁首「原價紀錄」連到獨立管理區，標題、筆數與本機保存說明始終可見；管理清單預設收合，按「展開個人原價紀錄清單」即可查看所有記錄的商品名稱、代碼與**「個人紀錄原價／非官方」**價格，也可再次收合。清單為空時展開會顯示新增方法；儲存／清除結果與儲存空間錯誤提示不會被清單收合隱藏。即使商品目前不在地圖，也能修改、清除既有紀錄。接受 NT$0.01～99,999.99 的正數金額，最多兩位小數；不接受逗號、貨幣符號、指數或負數。
- 官方公開 `MapProductInfo` 只提供商品 `code`、`name`、`qty`，`MapProductImage` 只提供 `imageUrl`；兩者都**沒有可用商品代碼核對的官方原價或逐件效期**。[全家鮮食商品頁](https://www.family.com.tw/Marketing/zh/FreshFood/Product)雖有部分原價，卻沒有可對照的同一商品代碼，不能依名稱、圖片或模糊配對當作官方定價。本網站不使用個人紀錄推算結帳價格；只有上述特定收據參考價會顯示當次逐件五折推算，不把個人紀錄或參考價宣稱為官方／實際結帳價格。

## 本機執行

建議 Node.js 24 LTS（產生目錄快照使用 Node 24 的 TypeScript 型別移除功能）；其餘開發指令仍支援 Node.js 20.19+ 或 22.12+。在此儲存庫目錄執行：

```sh
npm ci
npm run update:stores
npm run dev
npm test
npm run check
npm run build
```

`npm run update:stores` 對公開目錄**只發一次 POST**，驗證後產生被 Git 忽略的 `public/store-directory.json`；失敗會以非零狀態退出且不沿用舊檔。沒有此檔時 UI 會明示 3 公里名單無法讀取，而非顯示假空清單。建置產物位於 `dist/`，Vite 的 `base` 已設為 `/familymart_map/`；工作流程會先取得新快照，才打包並發布至 GitHub Pages。

## 資料與隱私

- 商品資料直接呼叫 `https://stamp.family.com.tw/api/maps/MapProductInfo`，使用公開地圖代碼 `202106302`（友善食光）與 `202208202`（挖寶專區）。店舖目錄來源為 `https://family.map.com.tw/famiport/api/dropdownlist/Select_StoreName`，**無 CORS**：僅建置階段由 Actions POST `{"store":""}`，訪客瀏覽器只讀取本站同網域靜態快照，不向該端點直接連線。快照內容只含舊店碼、店名、地址、座標及擷取時間／異常座標筆數，不含電話或個人資料；格式、唯一性和至少 4,000 間的筆數門檻均在發布前檢查。商品圖片僅在按「查看圖片」後向同站官方 `MapProductImage` 查詢，且只載入核可的官方 HTTPS 圖片網址。API 不使用會員權杖或登入憑證。
- 店代碼是分店合併鍵；商品代碼是個人原價紀錄及內建收據參考價的精確對應鍵。八種內建參考價只含同意公開的商品代碼、品名、單價與一般收據日期，不含收據圖片、號碼、交易時間或分店資料；不是儲存在個人 `localStorage`。收藏與個人原價分別保存在本機 `localStorage`，原價紀錄只保存商品代碼、顯示名稱和自己輸入的原價，**不送往任何 API、不需登入、換裝置不會同步**；清除瀏覽器網站資料後也不會保留。收藏只保存店代碼、店名和地址，不保存定位座標。原價資料無法讀取、格式損壞或無法寫入時會明確提示，本次編輯僅留在目前頁面，不覆寫損壞資料，也不清除收藏。瀏覽器定位僅在按「使用目前位置」後請求；查詢座標四捨五入至小數點後四位，只送至全家地圖 API。地區預設座標僅代表標示地點附近，非整個行政區的搜尋。
- 未設定查詢位置且未選郵遞區號時，會以固定參考座標查詢**收藏店代碼**，只顯示收藏店結果，不會誤把參考座標附近店家當作使用者附近店家。郵遞區號查詢以 `PostInfo` 傳入三位數郵碼、以 `0, 0` 作為 API 需求座標，不送出使用者定位，也不附上跨區收藏碼；已有的收藏另外查詢。附近位置圖為本站繪製的相對示意，不載入第三方圖磚。
- 同一位置／郵遞區號和同一組店碼的商品查詢在本頁記憶體快取五分鐘；手動強制重查至少間隔一分鐘。目錄快照也在本頁記憶體快取，商品按展開／收藏才按舊碼查詢，不對目錄所有店逐一請求。服務、格式或身分驗證錯誤會顯示錯誤，不會拿假資料代替；請避免頻繁要求官方服務。
